# HME_0.8_Preview_Experimental

HME 是一款《钢铁雄心 IV》MOD 地图编辑工具，可以直接在地图上查看和修改常用地图数据，减少手动查找和编辑大量脚本文件的麻烦。<br>
同时支持自定义 LLM API 来实现地块命名、资源填写等功能来代替极为繁琐的人工操作。

> 当前为 0.8 预览实验版，使用前请先备份你的 MOD。<br>
> 注意，本工具仍处于开发阶段，*可能*存在尚未被开发者发现的漏洞，*可能*会导致使用者产生**不可挽回的数据损坏**！<br>
> **再次提醒，使用前务必备份你的 MOD! MOD制作不易，请妥善保管数据！**

## 使用前须知

- 本工具仍处于开发和测试阶段，可能存在程序错误、功能不完整或保存结果不符合预期的情况。
- 使用前请备份完整的 MOD 工程、重要地图文件和游戏存档，不要直接使用唯一一份工程进行测试。
- 建议先在工程副本中少量修改，保存并检查无误后，再继续编辑。
- 因使用本工具、误操作、程序错误或文件兼容问题造成的 MOD 损坏、存档损坏、数据丢失或其他损失，由使用者自行承担，开发者不承担相关责任。
- 如果无法接受预览版本可能带来的风险，请暂时不要将本工具用于重要或无法恢复的项目。
- **开发者使用本工具已经完整开发了一套可用的 MOD 地图，尚未遇到任何严重的致命漏洞。仅作为参考案例。**

## 主要功能

- 查看和编辑 Province、State 与国家归属
- 地形、省份、政治、州域和补给地图模式
- Province 重新分配与飞地检查
- 地形刷子，以及地形修改的撤销和重做
- 铁路、补给中心、海峡和运河编辑
- 建筑坐标查看、移动、添加和删除
- 查看建筑等级
- State 属性、建筑、资源和本地化名称编辑
- 国家创建、国家颜色和基础国家信息编辑
- 胜利点与首都标记编辑
- State / Province ID 和名称查找
- 保存前数据检查
- AI 辅助命名、资源分配和战略区域生成
- 自动备份与外置热更新补丁支持

## 下载

请在仓库右侧的 **Releases** 页面下载：

`HME_0.8_Preview_Experimental.exe`

这是单文件版本，已经包含运行所需组件，不需要另外安装 Python，也不需要下载 `_internal` 文件夹。

## 如何使用

1. 下载并运行 `HME_0.8_Preview_Experimental.exe`。
2. 在编辑器中选择你的 HOI4 MOD 根目录。
3. 等待地图和 State 数据加载完成。
4. 选择需要的地图模式或编辑工具进行修改。
5. 修改完成后点击保存。

MOD 根目录通常应该包含这些目录或文件：

```text
map/
history/states/
common/
localisation/
descriptor.mod
```

## 使用建议

- 第一次使用前，请复制一份 MOD 作为备份。
- 大型地图首次加载可能需要一些时间。
- 修改地图文件后，建议先使用编辑器的数据检查功能，再进入游戏测试。
- 如果程序旁边存在 `patch` 文件夹，程序会优先加载其中的热更新文件；没有补丁时直接使用程序内置版本。
- Release 中的 `HME_Hot_Update_Guide_zh-CN.txt` 提供外置热更新补丁的使用说明。
